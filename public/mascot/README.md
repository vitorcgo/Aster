# Mascote Aster

O frontend usa `idle.svg`, `thinking.svg`, `writing.svg` e `success.svg` conforme o estado da consulta. Para trocar a arte, substitua os SVGs mantendo os nomes, ou altere o caminho em `components/Mascot.tsx` se usar outro formato. Em erro, o mascote volta a `idle` e balança a cabeça uma vez; clicar nele mostra `success` por um instante.
